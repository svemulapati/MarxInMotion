# Marx in Motion

Das Kapital, all three volumes, explained chapter by chapter with animations simple enough for a kid to follow.

- Next.js 16 (App Router), Tailwind CSS 4, TypeScript
- Visual direction: [format.obys.agency](https://format.obys.agency/)
- Live: https://marxinmotion.vercel.app

```bash
npm install
npm run dev
```
